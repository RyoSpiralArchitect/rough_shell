# Examples

This directory holds curated examples distilled from real `rough_shell` runs.

The raw session artifacts usually live under `.rough-shell-runs/`, which is intentionally ignored by git. The files here are the committed, human-readable versions of the runs that taught the runtime something important.

Current examples:

- [desert-mermaid-fictional-domain.md](./desert-mermaid-fictional-domain.md)
  A Gemini run where a creative question was first treated as missing information, then corrected into a fictional/speculative domain.
